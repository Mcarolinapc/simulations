# Simulations - Mi Primer Fork en GitHub 

Este repositorio tiene un valor puramente **sentimental y de referencia**. Fue el primer *fork* que realicé en mi etapa de aprendizaje con Git y GitHub, por lo que he decidido mantenerlo en mi perfil como un recordatorio de mis inicios en el control de versiones.

---

##  ¿Qué es este código?

Se trata de un proyecto base (*boilerplate*) desarrollado en **Java con Spring Boot**. Sirve como un excelente ejemplo de referencia rápida sobre cómo estructurar una **API REST** completa con operaciones CRUD siguiendo una arquitectura limpia por capas.

###  Estructura del Sandbox
El proyecto implementa los dominios de `Player`, `Simulation` y `Subscription` divididos en:
* **`controller`**: Controladores REST (`@RestController`).
* **`service`**: Capa de lógica de negocio.
* **`repository`**: Capa de acceso a datos.
* **`model`**: Entidades del sistema.
